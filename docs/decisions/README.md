# Architecture Decision Records

Store material architecture, protocol, technology and experimental decisions in this directory.

Use one file per decision, named:

`NNNN-short-title.md`

Each record should include:
- Status: proposed, accepted, superseded or rejected
- Date
- Context
- Decision
- Alternatives considered
- Consequences
- Affected documents/code
- Validation or evidence

Do not silently change approved contracts. Update the relevant document and record the decision.
