# OfflineLink Zambia — Stage 0 Documents

These documents establish the proposed shared requirements, architecture, API contract, synchronization protocol and test plan before implementation.

## Files
- `requirements.md` — approved objectives, research questions, scope and requirements.
- `architecture.md` — component boundaries and system flow.
- `api-contract.md` — proposed API inventory and contract rules.
- `sync-protocol.md` — synchronization semantics, correctness and metrics.
- `test-plan.md` — validation and acceptance gates.
- `decisions/` — decision record template and Stage 0 baseline decision.

## Important
The API paths and some protocol details are proposed, not implemented or approved yet. Review and freeze them before generating dependent code. Do not treat this folder as evidence that features already exist.

## Suggested next step
Review Stage 0 documents and resolve the open items in `api-contract.md` and `sync-protocol.md`. Then approve the baseline and begin Layer 1 implementation.
